# 2.1. Data Structure -MySQL

## Project Description 📄

The goal of this project is to learn **how to create and model an SQL database**. To do this, two databases have been created, one to manage an optical shop and another to manage the service of a pizzeria.
## Technologies used 💻

- **phpMyAdmin**
- **MySQL**
- **GitHub**
##  How to run it ▶️

**1.** Open phpMyAdmin.

**2.** Import the .sql files.
